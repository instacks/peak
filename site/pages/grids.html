Per-element knobs

The layouts read a few custom properties you can set per element, with a style attribute or a class of your own. They inherit like any custom property.

  • --peak-gap: the gap of grids, clusters, switchers, media objects and sidebar layouts.
  • --peak-grid-min: the narrowest column of a grid (an input, 15rem by default).
  • --peak-cols: the most columns of .peak-grid (3).
  • --peak-sidebar-width: the sidebar's width in .peak-with-sidebar (an input, 16rem).
  • --peak-switch-at: where .peak-switcher stacks (40rem).
  • --peak-media-min: the narrowest the text of .peak-media gets before it wraps below the image (16rem).

Auto grid

.peak-grid-auto fits as many columns of at least --peak-grid-min as there is room for, and a single column never overflows a narrow container. Cards in it line up: each fills its row's height and its footer sits at the bottom.

Column grid

.peak-grid has at most --peak-cols equal columns (3 by default), none narrower than --peak-grid-min. With less room it drops to fewer columns by itself. Items can span: .peak-span-2, .peak-span-3 (once the grid has that many columns) and .peak-span-full. Make the window narrower: the spans give way as the columns go.

A container query can't read --peak-grid-min, so spans switch on at the widths where the grid has 2 and 3 columns with the default 15rem minimum (31rem and 47rem). With a smaller minimum the grid gets its extra columns before the spans switch on; with a larger one a span can add a column. .peak-span-full is always safe.

Cluster

.peak-cluster is a wrapping row with even gaps: buttons, badges, chips, logos. Like a paragraph, it has space below it, also on a <div>. Children lose their block margins so they line up. Modifiers: .justify-center, .justify-end, .justify-between, .align-start, .align-end, .align-baseline.

Sidebar layout

.peak-with-sidebar puts an <aside> (or .peak-sidebar) next to the content, in either order. When the content would get narrower than 60%, the aside wraps above or below it: no breakpoint. .sticky keeps the aside in view while the content scrolls (offset by --peak-sticky-offset).

Media object

.peak-media: an image or icon beside text. The text wraps below the image when there is no room for at least 16rem of it (--peak-media-min). .center centers them vertically.

Switcher

.peak-switcher puts its items in one row while it is at least --peak-switch-at wide (40rem), and stacks them all once it's narrower: never a half-wrapped row. Five or more items always stack.

PatternUse for
.peak-grid-autoCards and tiles of equal importance, any number
.peak-gridA fixed maximum of columns, items that span
.peak-clusterInline things of different widths: buttons, tags, logos
.peak-switcherA few equal blocks that should line up or stack, together

.peak-mediaAn avatar, icon or thumbnail beside text
