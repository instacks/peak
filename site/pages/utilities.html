Text colors

.peak-text-primary, -secondary, -contrast, -accent, -muted, -success, -danger, -info. There's no warning text color: warning is too light for text.

Heading sizes

.peak-h1, .peak-h2, .peak-h3, .peak-h4, .peak-h5 and .peak-h6 give any element a heading's size. See Typography.

Text alignment

.peak-text-start, .peak-text-center and .peak-text-end align text by the writing direction, so -end is the right edge in English and the left edge in Arabic. Children inherit it: on an hgroup it aligns the eyebrow, the heading and the subtitle together.

Margin resets

.peak-mt-0 removes the space before an element (a heading that follows other content gets some), .peak-mb-0 the space after it (paragraphs, cards). Use them where a layout already spaces its items.

Visually hidden

.peak-visually-hidden hides an element on screen but keeps it for screen readers: a legend for a row of chips, a label for an icon button. It shows again when something inside it has focus.

Show and hide by width

Hide an element below a viewport width, or from that width up. The usual pair: a sidebar on wide screens, and on narrow ones a button that opens the same links in a drawer.

Scoping

  • .peak and .peak-ignore choose where the scoped build applies.
  • data-peak-scope starts a new set of inputs (Theming).
  • data-peak-anchor anchors a popover or dropdown to its trigger (Menus and popovers).
