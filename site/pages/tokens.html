Inputs

Set these on :root, or on an element with data-peak-scope or data-theme (see Theming). Ranges are what the contrast tests cover; values outside them work but aren't checked. "Unset" inputs have no default: they fall back to another input until you set them. Try them in the customizer.

Derived tokens

Computed from the inputs for both color schemes. Read them in your own CSS with var(); don't set them (set the inputs instead). Swatches are live.

Roles

Primary, secondary and contrast each come with the same set:

TokenUse
--peak-primaryText color: links, the current item
--peak-primary-hoverHovered links; text on the tint
--peak-primary-fillButton and solid badge background
--peak-primary-hover-bgHovered button background
--peak-primary-tintLight background: badges, callouts, selected chips
--peak-primary-subtleA faint wash
--peak-primary-focusFocus ring (opaque)
--peak-primary-underlineLink underline
--peak-on-primaryText on the fill

Replace primary with secondary or contrast for the others (contrast has no fill or tint of its own: it is the fill). --peak-primary-inverse is Pico's name for --peak-on-primary.

Accent and status

  • --peak-accent (text), -hover, -fill, -hover-bg, -subtle, and --peak-on-accent.
  • --peak-success, --peak-warning, --peak-danger, --peak-info, each with -hover, -subtle, -border and --peak-on-*. Warning is a fill, not a text color.
