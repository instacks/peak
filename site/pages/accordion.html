Accordion

Every <details> is an accordion item. Give several the same name and only one is open at a time (the browser does this, no script). Where the browser supports ::details-content and interpolate-size, opening and closing are animated, except with reduced motion.

What is Peak?

A CSS layer on top of Blades CSS.

Does it need JavaScript?

No. One optional script remembers the light/dark choice.

Which browsers?

Chrome and Edge 123+, Firefox 128+, Safari 18+.

Grouped

.peak-accordion groups the items in one box, separated by rules. .flush drops the box.

Tabs

.peak-tabs turns a group of exclusive <details> into tabs: the summaries form the tab row and the open one's content is the panel. Up to eight tabs. Where ::details-content isn't supported, the same markup is an exclusive accordion.
