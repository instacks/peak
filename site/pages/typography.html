Size and scale

The root font size is fluid: clamp(--peak-font-size-min, 0.875rem + 0.5vw, --peak-font-size-max), 1rem on a phone and up to 1.3125rem on a large screen. Everything in rem (headings, spacing, controls) grows with it.

Headings form a modular scale: h6 is 1rem and each level up multiplies by --peak-type-ratio (1.15). The sizes are tokens: --peak-h1 … --peak-h6.

Headings get balanced line breaks (text-wrap: balance) and letter-spacing from --peak-heading-tracking: h2–h4 the value, h1 4/3 of it, .peak-display 5/3, h5 and h6 none. Line heights tighten per level around --peak-heading-line-height.

Weights and fonts

  • --peak-font-weight for text, --peak-heading-font-weight for headings.
  • --peak-display-weight: h1 and .peak-display; --peak-subheading-font-weight: h4–h6; --peak-button-font-weight: buttons. Unset, each follows the heading or body weight.
  • --peak-font-family, --peak-font-family-heading and --peak-font-family-mono take any font stack. The customizer offers system-font presets that need no downloads.

Eyebrow

A short line above a heading. Inside an <hgroup> it needs no class: the first child is the eyebrow when a heading follows it. Elsewhere, use .peak-eyebrow, with .secondary or .contrast for another color.

Display and lead

.peak-display is a headline above h1, fluid between --peak-display-size-min and --peak-display-size-max. .peak-lead is an introduction paragraph: a step up the scale, muted, at a readable width.

Prose

.peak-prose sets running text, such as CMS output or an article: lines no longer than --peak-measure (65ch), pretty line breaks, images and videos that fit the column, and tables that scroll sideways instead of widening the page. Add .center to center the column.

A short article

Long lines are hard to read. Prose keeps the measure in check, and media inside never overflow the column, whatever size the author uploaded.

Blades draws every <article> as a card. On an article, .peak-prose turns it back into running text: no box, and its <header> and <footer> are no bands. That's the markup for a blog post or CMS output.

Heading anchors

A .peak-anchor link inside a heading appears on hover and keyboard focus (always on touch screens). Every heading in these docs has one.

Code blocks

A pre scrolls when its content is too wide or too tall. A shade along an edge shows there is more beyond it (CSS only). --peak-code-max-height caps the height. Blades' data-caption on the code adds a caption. 

@layer blades, peak.tokens, peak.base, peak.layout, peak.components, peak.utilities; /* a long line that scrolls sideways */

:root {
  --peak-hue: 250;
  --peak-chroma: 0.16;
  --peak-radius: 0.375rem;
  --peak-spacing: 1rem;
}
