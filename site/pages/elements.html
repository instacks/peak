Icons

.peak-icon draws any single-color SVG in the text color: the SVG is a mask, set with --peak-icon, over a box filled with currentColor. So an icon follows link colors, hover, the .peak-text-* colors and the color scheme, from one file. It's 1.25em square and scales with the text; .sm (1em), .lg (1.75em) and .xl (2.5em) change that, as does --peak-icon-size. It stays visible in forced colors and when printed without backgrounds. The icons here are from Lucide (ISC license).

A decorative icon next to its own text gets aria-hidden="true"; an icon that says something by itself gets role="img" and an aria-label, and an icon-only button gets its label on the button. The SVG's own colors are ignored; put a multi-color logo in an <img>.

The examples set the SVG as a data URI. A file works too, with two rules. Write its URL root-relative or absolute (url(/icons/mail.svg)): a browser may resolve a relative URL in a custom property against the stylesheet that uses it, Peak's, rather than your page (Chromium does). And serve it from the page's own site: browsers load mask images like fonts, so an SVG from another domain needs CORS headers, and a page opened as a file:// can't load one at all.
