How the palette is built

OKLCH describes a color by lightness, chroma (saturation) and hue. Peak keeps the lightness of each role fixed per color scheme and lets you choose hue and chroma. Because lightness decides contrast, every text and background pair stays readable for any hue, chroma, neutral tint and status hue in the tested ranges (WCAG 2: 4.5:1 for text, 3:1 for large text and controls). The test suite sweeps the full range of every color input.

The swatches on this page are live: change the hue in the customizer or switch the scheme in the header, and they follow.

Brand colors

--peak-hue and --peak-chroma set the primary color: links, buttons, focus rings, the current item in navigation. --peak-brand takes any color instead and uses its hue and chroma (lightness is still set per scheme).

:root { --peak-brand: #e4572e; /* or --peak-hue: 30; --peak-chroma: 0.17; */ }

Secondary and contrast

Secondary is the neutral ramp, tinted four times as strongly, unless --peak-secondary-hue makes it a color of its own. Contrast is the near-black (near-white in dark mode) of the text ramp.

Accent

A second hue for highlights used sparingly: badges, icons, a word in a headline. --peak-accent-hue and --peak-accent-chroma, or a picked color with --peak-accent-color.

Neutrals

Surfaces, text and borders come from a neutral ramp. --peak-neutral-chroma tints it toward the brand hue (0 is pure gray); --peak-neutral-hue tints it toward a hue of its own, and --peak-neutral-hue-dark uses another one in dark mode (warm paper by day, a cool night). --peak-ink-hue tints text separately from surfaces.

Status colors

Four hues share one chroma (--peak-status-chroma). Success colors valid fields and <ins>, danger invalid fields and <del>, warning <mark>. Warning is a fill color only: it is too light for text on a light page, so there is no .peak-text-warning.

Inserted, deleted and marked text.

Text on a fill

Each fill has an --peak-on-* token for text on it: --peak-on-primary, --peak-on-secondary, --peak-on-contrast, --peak-on-accent and --peak-on-success, -warning, -danger, -info.

primary secondary contrast accent success warning danger info

Higher contrast

With the system setting "increase contrast" (prefers-contrast: more), muted text and borders get stronger automatically. See Accessibility.
