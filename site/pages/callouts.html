Callouts

.peak-callout is a tinted note with a colored edge. A first <strong> or heading becomes its title. Colors as badges: default (primary), .secondary, .accent, .success, .warning, .danger, .info.

Note

The default callout uses the primary color.

Info

Peak needs no JavaScript for any component.

Success

Your theme was saved.

Heads up

Exact colors are outside the contrast guarantee.

Danger

Renaming an input is a breaking change.

A callout without a title, in the secondary color.

A heading as title

Any heading works as the first child too.

Use <aside> for a note beside the main text, or a <div> with role="note" or role="alert" when that describes it better.

Toasts

.peak-toast is a popover in the bottom corner at the inline end. With popover="manual" it stays until it's closed. A button with popovertarget opens and closes it without script; it slides in and out.

Theme saved.

Colors as callouts, shown as the start edge. Showing a toast after an action, or hiding it after a delay, needs a line of script:

const toast = document.getElementById("toast-saved"); toast.showPopover(); setTimeout(() => toast.hidePopover(), 4000);

One toast at a time: a second one in the same corner covers the first. Keep role="status" (or role="alert" for errors) so screen readers announce it.
