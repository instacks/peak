<meta name="color-scheme" content="light dark"> lets the page follow the visitor's system setting from the first paint. Leave it out, or set data-theme="light" on <html>, for a light-only page.

Setting inputs

Every color, size and space comes from the --peak-* inputs. Set them on :root for the whole page, or on an element with data-peak-scope or data-theme for one part of it:

:root { --peak-hue: 30; /* brand hue, 0–360 */ --peak-chroma: 0.14; /* brand saturation */ --peak-font-family: Charter, "Bitstream Charter", Cambria, serif; --peak-type-ratio: 1.25; /* a more dramatic heading scale */ --peak-spacing: 1.25rem; /* more room everywhere */ }

Try them in the customizer, which writes this CSS for you, and see every input in the token reference.

Cascade layers

Peak declares its layer order before any of its rules:

@layer blades, peak.tokens, peak.base, peak.layout, peak.components, peak.utilities;
  • blades: Blades and Pico, unmodified.
  • peak.tokens: the inputs, the derived tokens and the --pico-* bridge.
  • peak.base: element defaults (headings, sections, code blocks).
  • peak.layout: page structure and layout patterns.
  • peak.components: cards, badges, menus, dialogs…
  • peak.utilities: text colors, heading sizes, forced colors, print. Wins over components regardless of specificity.

CSS outside any layer beats all of them, so your own stylesheet overrides Peak with any selector. To put a rule between Peak's layers instead, write it into one:

/* Unlayered: wins over every Peak rule, even .peak-badge.solid */ .badge-big { font-size: 1rem; } /* In Peak's components layer: a utility class still beats it */ @layer peak.components { .my-card { border: 1px solid var(--peak-border); } }

Classes and variants

Peak's classes start with peak-. Variants reuse Pico's short names (.secondary, .contrast, .outline) and Peak's own (.accent, .success, .warning, .danger, .info, .solid…). They only mean something next to a Peak class:

Default Secondary Success, solid

The site-* classes (.site-nav, .site-footer…) are page chrome; see Navigation.

Building from source

git clone https://github.com/instacks/peak.git cd peak npm ci npm run build # dist/peak(.min).css and dist/peak.scoped(.min).css npm run watch # rebuild dist/peak.css on change npm run docs # this site, in _site/

Peak is bundled with Lightning CSS for modern targets only (the browserslist field in package.json). Broad targets would make it polyfill light-dark(), which breaks nested color schemes.
