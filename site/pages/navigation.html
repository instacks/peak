Site header

The site-* classes style a site's chrome. They're optional: a page that doesn't use them is unaffected.

  • .site-header around the navigation; .nav-sticky keeps it at the top while scrolling.
  • .site-nav on the <nav>: wrapping lists, the current page in bold.
  • .site-title for the brand link, with an optional logo image or SVG (height --peak-logo-size) and .site-subtitle after it.
  • data-nav-style="surface" or "bordered" on the header gives it a background (and a bottom rule) that runs to the viewport edges.
  • data-nav-align="start" on the nav puts the links right after the title.

Mobile menu

data-peak-menu="576", "768" or "1024" on the nav folds the links into a button below that viewport width. The button opens them in a native popover: Esc and a click outside close it, no JavaScript. Above the width, the wrappers disappear from the layout (display: contents) and the links are a normal row.

Dropdowns in the bar

Two ways to give a link sub-pages:

  • Pico's <details class="dropdown">, drawn like a nav link.
  • A .site-dropdown-toggle button and a ul[popover] in the same <li>: drawn as a link with a chevron that turns while open, and anchored (see Menus). Its color follows data-link-style (secondary or contrast).

In an open mobile menu, a <details> dropdown opens in place and pushes the links below it down. A popover can't: it sits in the top layer and floats over them. For a header that folds into a mobile menu, prefer <details>.

Sidebar navigation

.peak-sidebar-nav is a vertical list of links, the current page marked by a colored edge. Nested lists are open only on the branch that holds the current page (with aria-current="page"), so a long site stays short. The page list of these docs is one.
